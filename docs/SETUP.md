# mobpc Setup Guide

## Требования

- Windows 10/11
- Python 3.11+
- Flutter SDK 3.x
- Tailscale (рекомендуется) или Cloudflare Tunnel

## Установка агента

1. Клонируйте репозиторий
2. Перейдите в `agent/`
3. Создайте виртуальное окружение и установите зависимости
4. Запустите `python main.py`
5. Отсканируйте QR-код для привязки телефона

## Подключение через интернет

См. `scripts/setup-tunnel.ps1` и `scripts/install-agent.ps1`.
