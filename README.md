# mobpc

Управление Windows-компьютером с телефона. Телефон показывает экран ПК и работает как мышь, клавиатура, терминал и пульт. Подключение по QR-коду, в браузере — без установки приложений.

## Запуск в один клик

1. Установите Python 3.10+ (`winget install Python.Python.3.12`).
2. Дважды щёлкните **`start.bat`**.
   При первом запуске скрипт создаст окружение и установит зависимости. Кэш pip и временные файлы он кладёт в `.cache` внутри проекта.
3. Откроется страница **«Подключить телефон»** с QR-кодом. Наведите на него камеру телефона, подключённого к той же сети Wi-Fi.

Если Windows спросит про доступ Python к сети — разрешите для частных сетей.

**Подробная инструкция для пользователя: [docs/USAGE.md](docs/USAGE.md)** — подключение, разделы пульта, удалённый доступ из колледжа, как поставить игру на скачивание.

| Адрес | Что там |
|---|---|
| `http://127.0.0.1:8765/` | Лендинг проекта |
| `http://127.0.0.1:8765/connect` | QR-код и код привязки, список устройств (только на самом ПК) |
| `http://<IP-компьютера>:8765/app` | Веб-пульт для телефона |
| `http://127.0.0.1:8765/docs` | Документация API (Swagger) |

## Возможности

- **Экран** — трансляция до 15 к/с, клик касанием, правый клик долгим касанием, масштаб двумя пальцами, три режима качества. Неизменившиеся кадры не отправляются.
- **Мышь и клавиатура** — тачпад с жестами (тап, два пальца, удержание для перетаскивания), «живая» печать с телефона, включая кириллицу, залипающие Ctrl/Alt/Shift/Win, стрелки и F1–F12, сочетания по группам. Пока печатаете — видно экран ПК. Сочетания работают при любой раскладке.
- **Терминал и файлы** — PowerShell и cmd с потоковым выводом, история и `cd`; файловый менеджер, скачивание на телефон, загрузка на ПК.
- **Система** — CPU, память, диск, батарея; окна и процессы; музыка и громкость; буфер обмена; уведомления на экран ПК; сценарии (макросы); блокировка, сон, перезагрузка, выключение.
- **Через интернет** — кнопка «Доступ через интернет» на странице подключения (Cloudflare Quick Tunnel, агент сам скачивает cloudflared) или Tailscale с постоянным адресом.
- **Скачивание на ПК по ссылке** — поставить файл на загрузку прямо с телефона, с прогрессом и отменой; быстрые действия для Steam.
- **Не давать ПК засыпать**, пока работает агент, — чтобы компьютер был на связи, когда вас нет дома.

## Безопасность

- Код привязки создаётся **только на самом ПК**: запросы из сети и через туннель (заголовки `X-Forwarded-For`, `CF-Connecting-IP`) получают 403. Управлять туннелем через интернет тоже нельзя.
- Код одноразовый, 8 символов (31⁸ вариантов), живёт 5 минут; не больше 20 неверных попыток в минуту.
- Устройство получает JWT (HS256, 90 дней) с идентификатором; на странице `/connect` любое устройство можно отключить — токен сразу перестаёт работать.
- Опасные действия (выключение, удаление, завершение процесса) требуют подтверждения в пульте.
- Лимит команд в секунду, таймаут команд терминала, запрет вложенных макросов, текст уведомлений не может выполниться как код PowerShell.

## Структура

```
start.bat         — запуск в один клик
agent/            — Python-агент для Windows (FastAPI + WebSocket)
  main.py         — точка входа (--open, --port)
  server/         — HTTP/WebSocket API, настройки, определение сетей
  auth/           — привязка устройств и токены
  executor/       — исполнители команд: экран, ввод, терминал, файлы, система
  web/            — лендинг, страница подключения, веб-пульт (без фреймворков, офлайн)
  tests/          — автотесты (unittest)
mobile/           — Flutter-приложение для Android
shared/           — протокол команд (protocol.json)
scripts/          — автозапуск и туннели
docs/             — документация
presentation/     — презентация и речь для выступления
```

## Ручной запуск и тесты

```powershell
cd agent
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python main.py --open            # --tunnel — сразу включить доступ через интернет
python -m unittest discover -s tests -v
```

Настройки — переменные окружения с префиксом `MOBPC_` (например `MOBPC_PORT=9000`), см. `agent/server/config.py`.

## Протокол

Команды передаются как JSON через WebSocket `/ws?token=…`: `{"id", "type", "payload"}` → `{"id", "ok", "data", "error"}`. События (кадры экрана, вывод терминала) приходят как `{"type", "data", "id"}`. Полная схема — [shared/protocol.json](shared/protocol.json), 45 команд.

## Flutter-приложение

```bash
cd mobile
flutter pub get
flutter run
```

Сканер понимает и новый QR (ссылка `http://host:8765/app#pair=CODE`), и старый JSON-формат.
