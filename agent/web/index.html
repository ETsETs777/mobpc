Управляйте компьютером с телефона

mobpc показывает экран Windows на телефоне и превращает телефон в мышь, клавиатуру, терминал и пульт. Наведите камеру на QR-код — пульт откроется в браузере, устанавливать ничего не нужно.

Работает в домашней сети Wi-Fi, а с доступом через интернет — из колледжа, с работы, из любой точки мира.

Всё, что нужно, когда до компьютера не дотянуться

Разделы пульта окрашены, как кнопки на пульте телевизора: синий — экран, жёлтый — ввод, зелёный — терминал и файлы, красный — система. Те же цвета вы увидите в приложении.

Экран

  • Трансляция рабочего стола до 15 кадров в секунду
  • Касание по картинке — клик в этой точке экрана
  • Долгое касание — правый клик, двумя пальцами — масштаб
  • Три режима качества под скорость сети

Мышь и клавиатура

  • Тачпад с жестами, как у ноутбука
  • Печать с телефона сразу на ПК, по-русски тоже
  • Горячие клавиши: копировать, сменить окно, язык
  • Переключение слайдов презентации

Терминал и файлы

  • PowerShell и cmd с выводом в реальном времени
  • Файловый менеджер по всем дискам
  • Скачивание файлов на телефон и загрузка на ПК
  • Открытие файла на компьютере одним касанием

Система

  • Нагрузка процессора, память, диск и батарея
  • Окна и процессы: показать, свернуть, завершить
  • Музыка, громкость, буфер обмена, уведомления
  • Блокировка, сон, перезагрузка, выключение

Подключение за минуту

Не нужно настраивать роутер, знать IP-адрес или ставить приложение из магазина.

  1. 1

    Запустите агент

    Дважды щёлкните start.bat. Скрипт сам поставит зависимости и откроет страницу с QR-кодом.

  2. 2

    Наведите камеру

    Телефон в той же сети Wi-Fi откроет пульт по ссылке из QR-кода. Код одноразовый и действует 5 минут.

  3. 3

    Управляйте

    Телефон запомнит компьютер. В следующий раз достаточно открыть пульт с главного экрана телефона.

Как устроено

На компьютере работает агент на Python. Телефон отправляет ему команды в формате JSON по WebSocket, агент проверяет токен и выполняет команду через Windows API.

Одна команда — одно сообщение

// телефон → компьютер
{ "id": "7f3a…", "type": "mouse.click",
  "payload": { "x": 960, "y": 540, "button": "left" } }

// компьютер → телефон
{ "id": "7f3a…", "ok": true,
  "data": { "clicked": true } }

Кадры экрана уменьшаются до нужной ширины и сжимаются в JPEG. Если на экране ничего не изменилось, кадр не отправляется — трафик на статичном экране падает в разы.

Доступ к компьютеру только с вашего разрешения

Пульт может всё, что может пользователь за клавиатурой. Поэтому каждое подключение начинается с действия на самом компьютере.

Код создаётся только на ПК

Запросы на новый код из сети и через туннель отклоняются. Подключиться можно, только если вы показали QR-код.

Одноразовый код на 5 минут

После привязки код сгорает. 31⁸ вариантов и не больше 20 попыток в минуту — подобрать его нельзя.

Подписанный токен

Телефон получает токен JWT со сроком 90 дней. Секрет подписи хранится только на компьютере.

Отключение в один клик

На странице «Подключить телефон» видно все устройства. Отключённый телефон сразу теряет доступ.

Подтверждение опасных действий

Выключение, удаление файлов и завершение процессов требуют подтверждения на телефоне.

Защита от ошибок и перегрузки

Лимит команд в секунду, таймаут для команд терминала, запрет вложенных сценариев.

Не только дома

Сидите в колледже, а дома нужно поставить игру на скачивание или забрать файл? Включите доступ через интернет — открывать порты на роутере не нужно.

Одна кнопка

Cloudflare Tunnel

Кнопка «Включить» на странице подключения. Агент сам скачает cloudflared и выдаст адрес https://….trycloudflare.com. Аккаунт не нужен, на телефон ничего ставить не нужно.

Адрес меняется при перезапуске агента — перед уходом отсканируйте свежий QR.

Постоянный адрес

Tailscale

Частная сеть между вашими устройствами на базе WireGuard. Поставьте Tailscale на ПК и телефон, войдите в один аккаунт — адрес 100.x.x.x не меняется.

winget install Tailscale.Tailscale
